What is stored?

Dataset provenance → candidates → model runs and split membership → metrics and predictions. The review queue joins predictions back to the source records through foreign keys.

TP: pulsar found · FP: false alarm · FN: missed pulsar · TN: correctly rejected noise.

Scores are model outputs, not calibrated probabilities or proof of a new discovery. Saved labels allow benchmark evaluation; real deployment would require separate scientific validation.
