# Assignment 9 — Reading List

Özcan Öztürk · 230408011 · CMP309 Web Programming

A React client and Express API for a reading list. Data stays in server memory
and resets to six seed books when the server restarts.

The server will support GET, POST, PUT, PATCH and DELETE, with manual validation.
The client will use a dedicated Fetch module, server-side filters and restricted CORS.
